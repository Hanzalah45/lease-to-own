What shipped

Backend & frontend, built together

Per the technical plan, Milestone 1 is environment setup, database schema, role-based authentication, and the base API structure — no lease pricing, risk scoring, or payment logic yet. That's intentional; those are Milestones 2–8.

Backend — Laravel API

  • Full database schema across every entity in the plan Customers, Applications, Lease Agreements, Equipment Units + service history, Risk Profiles + red flags, Contracts, Payments, Admin permissions — plus a GPS Events table reserved for the Phase 2 tracking upgrade.
  • Role-based authentication (Laravel Sanctum) Two account types — Customer and Admin. Admin access splits into five permission areas: application review, risk assessment, contract generation, equipment tracking, payment tracking.
  • Base REST API for every module Routes and controllers scaffolded and ready — business logic lands module by module in the coming milestones.
  • Third-party connection points prepared Stripe, Plaid, SendGrid, and QuickBooks each have a configuration slot ready to receive live credentials when those milestones start.

Frontend — Next.js

  • Customer portal and Admin dashboard Separate, role-gated sections with their own navigation.
  • Working registration, login, and logout Customers self-register; admin accounts are created by an existing admin, never through public signup.
  • Admin can manage other admins Create accounts and assign any combination of the five permission areas.
  • Branded to the approved identity PROSTART Leasing logo, Barlow / Barlow Condensed type, red-on-black palette.
  • Responsive down to mobile Navigation collapses to a menu below tablet width.

Verified, not just built

  1. Customer registers and lands on their dashboard.
  2. Admin logs in and sees only the sections their permissions allow.
  3. Admin creates a second admin account and assigns it specific permissions.
  4. Role checks are enforced twice — once in the interface, again by the API itself.
